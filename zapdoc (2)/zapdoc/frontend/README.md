# ZapDoc Frontend (Flutter)

A CamScanner + iLovePDF style app. All image/PDF processing happens on the
Python backend — this app is the camera + UI layer.

## What's included

```
lib/
  main.dart                        # App entry
  models/
    scan_page.dart                 # One scanned page (raw + processed + corners)
  services/
    api_service.dart               # All HTTP calls to the Python backend
  screens/
    home_screen.dart               # Bottom nav: Documents / Scan / Tools
    scan_screen.dart               # Camera capture + gallery import
    crop_screen.dart               # Draggable-corner crop + filter picker (color/gray/bw/enhance)
    multipage_screen.dart          # Reorderable page grid -> "Save as PDF"
    documents_screen.dart          # List of previously saved PDFs
    tools_screen.dart              # iLovePDF-style grid: merge/split/compress/rotate/
                                    #   watermark/protect/unlock/OCR
    document_viewer_screen.dart    # Result screen: open / share a produced file
```

## Setup

This repo contains only the `lib/` Dart source + `pubspec.yaml` — the native
Android/iOS/etc. scaffolding is generated by the Flutter tool (it's large and
platform-specific, so it isn't hand-written here).

```bash
cd frontend
flutter create .          # generates android/, ios/, etc. around the existing lib/
flutter pub get
```

Then follow `android_permissions.md` to add camera/internet permissions to
the generated `AndroidManifest.xml` (and `Info.plist` for iOS).

## Point the app at your backend

Edit `lib/services/api_service.dart`:

```dart
static const String baseUrl = "http://10.0.2.2:8000"; // Android emulator default
```

- Android emulator → `http://10.0.2.2:8000`
- iOS simulator → `http://127.0.0.1:8000`
- Physical phone → `http://<your-computer's-LAN-IP>:8000` (phone and computer must be on the same Wi-Fi)
- Production → your deployed HTTPS URL

## Run

```bash
flutter run
```

## Notes / next steps

- The corner-drag UI in `crop_screen.dart` is intentionally simple (plain
  `GestureDetector` handles) — swap in a package like `flutter_doc_scanner`
  UI polish later if you want magnetic snapping/animations.
- `multipage_screen.dart` uses the `reorderables` package for drag-to-reorder;
  swap to `ReorderableGridView` if you prefer a stricter grid.
- Add local search/rename/delete to `documents_screen.dart` as needed.
- For production, put the backend behind HTTPS and add auth (e.g. an API key
  header in `api_service.dart`) since it currently accepts anonymous requests.
